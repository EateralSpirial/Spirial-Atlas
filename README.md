## 展示原则

每个项目统一使用独立 Markdown 文档，并采用同一结构：

1. 项目定位
2. 解决的问题
3. 核心亮点
4. 系统结构
5. 展示价值
6. 当前状态
7. 下一步

这样后续可以把文档直接转成项目卡片、项目详情页、个人作品集页面或对外介绍材料。
