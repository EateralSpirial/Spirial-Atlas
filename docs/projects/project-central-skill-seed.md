# central-skill-seed

## 1. 项目定位

central-skill-seed 是一个极小化的技能种子项目，用于生成完整的项目级上下文维护技能包。

## 2. 解决的问题

- 项目在长期迭代中容易丢失背景信息。
- 技能包如果一开始过重，会增加安装和维护成本。
- 不同项目需要拥有自己的本地上下文演化能力。

## 3. 核心亮点

- 使用 seed skill 到 full skill 再到 project-level skill 的生成链路。
- 种子本身保持极小，只保留必要核心文件。
- 生成后的项目可以维护自己的上下文结构。
- 明确命名、引用源和边界规则。

## 4. 系统结构

- SKILL.md
- ITERATION_RULES.md
- PROJECT_REFERENCES.md
- full-skill 蓝图目录
- 生成后的项目级技能

## 5. 展示价值

展示 AI 工具生态、技能包设计、项目初始化和上下文维护能力。

## 6. 当前状态

种子结构和生成链路已经定义清楚。
