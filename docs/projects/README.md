# 项目展示索引

本目录按照统一结构整理 Spirial Atlas 中适合展示的项目。每个项目独立成文，便于后续做成网页卡片、详情页或作品集导航。

## 统一文档结构

每个项目文档统一包含：

1. 项目定位
2. 解决的问题
3. 核心亮点
4. 系统结构
5. 展示价值
6. 当前状态
7. 下一步

模板见：[project-template.md](./project-template.md)。
