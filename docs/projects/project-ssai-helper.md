# SSAI Helper

## 项目定位

SSAI Helper 是面向小型企业的本地服务系统。它把员工入口、脚本库、浏览器操作、AI 辅助和项目迭代管理拆成可运行的 Windows 服务组合。

## 解决的问题

- 小型企业常见流程高度依赖人工重复操作。
- 员工需要简单入口，管理员需要独立治理入口。
- 自动化脚本需要申请、审核、分发、更新和灰度发布链路。

## 核心亮点

- 员工日常界面与管理员管理界面分离。
- 主服务负责登录、脚本执行、反馈、执行模式和需求入口。
- 管理系统负责账号、设备、脚本创建单、安装入口和发布管理。
- 脚本库既支持人工运行，也支持 AI 调用。
- 支持 Windows 机器级安装、更新和卸载。

## 系统结构

- 员工主服务界面
- 项目开发与迭代管理系统
- Agent 驱动引擎
- 浏览器操作系统
- 脚本库
- 脚本创建单
- Windows 服务安装包

## 展示价值

展示小型企业自动化产品设计、Windows 服务工程、脚本系统、后台管理和 AI 工作流整合能力。
