# GESA

## 项目定位

GESA 是企业服务空间架构项目，用于整理组织、空间、资源、任务和界面之间的关系。

## 解决的问题

- 企业工具分散。
- 大型系统需要区分不同读者视角。
- 复杂项目需要清楚的模块边界和文档边界。

## 核心亮点

- 组织图、共享空间、个人工作区和企业界面统一设计。
- 企业文档和开发文档分离。
- 空间、对象、界面、流程和数据模型分开描述。
- 单个文档只解释一个核心概念。

## 系统结构

- 组织图
- 共享空间
- 个人工作区
- 数据模型
- 企业界面

## 展示价值

展示大型系统抽象、企业产品设计、对象建模和文档架构能力。

## 当前状态

架构设计与文档系统阶段。

## 下一步

- 补充数据结构。
- 设计前端原型。
- 建立最小可运行 Demo。
