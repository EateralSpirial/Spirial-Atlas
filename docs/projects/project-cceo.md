# CCEO

## 项目定位

CCEO 是本地 Codex 生态治理台，用浏览器界面统一管理角色、项目、会话、知识库、渠道和定时循环。

## 解决的问题

- 本地 AI 工作流分散在命令行、目录、配置文件和历史会话中。
- 长期项目需要角色、会话、知识库和项目路径之间的稳定关联。
- 自动化循环需要可观察、可停止、可验证的控制面。

## 核心亮点

- 提供 Overview、Manager、Personas、Sessions、Knowledge Bases、Projects、Cron、Channels 等工作面。
- 使用 TypeScript、React 与 Express 构建本地优先的控制台。
- 支持会话索引、项目注册、知识库状态检查和渠道配置。
- 支持项目级循环任务的扫描和控制。
- 强调运行态、时间戳、输出摘要和外部结果验证。

## 系统结构

- 前端控制台
- Express API 服务
- 角色与项目注册表
- 会话索引
- 知识库状态检查
- 渠道配置面板
- 项目级定时循环管理

## 展示价值

展示 AI 工作台、开发者工具、前后端整合、本地优先产品和长期项目治理能力。
