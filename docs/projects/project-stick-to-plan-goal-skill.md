# stick-to-plan-goal-skill

## 1. 项目定位

stick-to-plan-goal-skill 是一个轻量技能，用于在长计划、长目标和多轮任务中保存最小必要执行状态。

## 2. 解决的问题

- 长任务容易在恢复执行后丢失当前步骤。
- 多轮调试、部署和实现过程需要保留已验证事实。
- 状态记录过重会变成低质量日志。

## 3. 核心亮点

- 使用项目本地文件保存最小状态。
- 只记录目标、状态、当前步骤、已完成、下一步、阻塞和接触文件。
- 文件保持短小，便于快速恢复。
- 不保存密钥、长日志或完整聊天记录。
- 适合部署、发布、多步骤实现和调试任务。
